## 📌 Featured Projects

### 1. [LabelHub AI MVP](https://github.com/SUCHA-main/labelhub-ai-mvp)

一个 AI 辅助数据标注 MVP，支持动态表单、Mock AI 审核、角色流程和 Docker 部署，适合作为 AI 全栈项目展示。

AI-assisted data labeling MVP with dynamic forms, mock AI review, role-based workflow, and Docker support.

- Tech: React, Node.js, Express, AI review workflow, Docker

### 2. [AI WeChat Digest MVP](https://github.com/SUCHA-main/ai-wechat-digest-mvp)

一个个人 AI 晚报系统，可以从 RSS 抓取文章，进行 AI / Mock 总结，按重要性分组，并生成每日摘要和推送框架。

Personal AI digest system for RSS fetching, article summarization, daily reports, and push workflow.

- Tech: Node.js, Express, SQLite, RSS, Mock / DeepSeek / Ollama AI Provider, Docker

### 3. [Go WebSocket Chatroom](https://github.com/SUCHA-main/go-websocket-chatroom)

一个 Go WebSocket 实时聊天室，支持注册登录、在线人数、历史消息、emoji、本地表情包，以及本地 Ollama AI 助手。

Real-time WebSocket chatroom with login, emoji, stickers, message history, and local AI assistant support.

- Tech: Go, WebSocket, Session login, Real-time broadcast, Ollama

### 4. [Fooocus Chinese Local Patch](https://github.com/SUCHA-main/fooocus-zh-local-patch)

一个非官方 Fooocus 中文本地 UI 补丁，包含中文界面、常用预设、Styles 简化和本地启动优化。

Unofficial local Chinese UI patch for Fooocus, focused on presets, style simplification, and local launch optimization.

- Tech: Fooocus, Stable Diffusion, SDXL, UI Patch, Chinese localization

## 🧠 How I learn

- 用 AI 辅助编程，但不把 AI 当作替代思考的工具
- 先做能跑起来的 MVP，再逐步优化体验和工程结构
- 每个项目都尽量留下 README、截图、启动方式、Docker 支持和复盘记录
- 比起收藏教程，我更相信“做一个能展示的小项目”

Build first, review carefully, improve step by step.
