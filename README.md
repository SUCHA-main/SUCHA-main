

### 选几个作品

**[AI WeChat Digest](https://github.com/SUCHA-main/ai-wechat-digest-mvp)**  
从 RSS 收集到内容筛选、摘要与个人晚报的完整流程。支持本地演示模式，也可接入大模型。

**[Go WebSocket Chatroom](https://github.com/SUCHA-main/go-websocket-chatroom)**  
用 Go 和 WebSocket 实现实时聊天室，练习连接管理、会话、消息广播与断线重连。

**[Luanhua Site](https://github.com/SUCHA-main/luanhua-site)**  
用 Astro 搭建的个人网站，收纳项目、技术笔记，以及一些尚在完善的想法。
